Assessment Security & Proctoring Setup

Configure and test anti-cheating protection rules before launching the worksheet.

Quick Presets:

1. Tab Switch Tracking

Page Visibility API

Detects when the student switches away to another browser tab or minimizes the window. Accurately calculates and logs the total duration (seconds) spent outside the test tab.

2. Window Blur Tracking

Window Focus / Blur

Detects when the browser window loses focus to external desktop software (such as ChatGPT, Notepad, Discord, split-screen windows, or secondary monitors).

3. Disable Right-Click

Context Menu Lock

Completely disables the browser's mouse right-click pop-up menu, preventing students from using "Inspect Element", "View Source", or right-click web searches.

4. Block Copy & Paste

Clipboard API Shield

Restricts clipboard access so students cannot copy exam questions to search engines or paste pre-written solutions into short or essay answer boxes.

5. Enforce Fullscreen Mode

Fullscreen API

Forces the assessment into immersive full-screen mode upon start. Exiting full-screen (e.g., pressing Esc or resizing window) triggers an immediate security alert.

6. Block DevTools Shortcuts

Keyboard Interceptor

Intercepts and blocks developer keys like F12, Ctrl+Shift+I (Inspect), Ctrl+Shift+J (Console), and Ctrl+U (View Page Source).

7. 3-Strike Auto-Submission

Disqualification Rule

Enforces a 3-strike penalty system (Strike 1: Warning, Strike 2: Severe Warning, Strike 3: Disqualification). Auto-submits the worksheet upon 3 rule violations.

8. Live Security Audit Log

Real-time Test Console

Displays an interactive floating console at the bottom-right of the worksheet, logging every security event, tab switch, and duration in real time for effortless testing.
